# content/v2 — per-building inputs for the painted village (v2)

The v2 shell (`village/v2/index.html`, `app.js`, `style.css`, `data/map.js`, `map/`) is **shared and frozen**.
The maps follow the memory-palace registry (`/data/sectors.json`, `/data/buildings.json`):
`#/` is the world map of the 16 sectors (S09 Vallée Verte lies outside the walls), and `#/quartier/<slug>` is
a painted map of one sector (slug = sector id without `Sxx_`, e.g. `S09_nature` → `nature`) with a click area
for every building **and** every `ST_` verb street of that sector (`content/v2/map.json` → `data/map.js`).

Buildings are discovered **at runtime**: for every building on a sector map the app tries
`village/v2/data/<id>.js`; a building whose data file loads is **live** (clickable, opens `#/<id>`), every
other one shows **bientôt** (streets show *rue des verbes · bientôt*). Nothing has to be registered anywhere.
Verb streets go live the same way. **Street rule: `id` = the `ST_` id lowercased** (`ST_liens` → `st_liens`):
`content/v2/st_liens/layout.json` with `"building": "st_liens"`, main room key `st_liens`, `"building_id": "ST_liens"`
and `"sector_id"` → `village/v2/data/st_liens.js`, opened at `#/st_liens`. (The `ST_` prefix is kept because
stripping it would collide with building ids such as `ciel`, `riviere` or `jeux`.)

**Naming rule: `id` = `building_id` without its `Bnn_` prefix** (`B29_plage` → `plage`, `B39_eglise` → `eglise`).
The only exceptions are legacy ids already in `map.json` (`B06_marche` → `boulangerie`, the S02 garage of
`B05_maison` → `garage`). The S16 Parc des Curiosités is painted and being built building by building
(`B52_miroirs` → `miroirs`, the red-and-white striped mirror tent, is live); the cimetière is not built.

Put the registry ids at the top level of `layout.json`; `build_v2.py` copies them into `data/<id>.js`
and the app places the building with them (it falls back to `map.json` for older layouts):
```jsonc
{ "building": "plage", "building_id": "B29_plage", "sector_id": "S09_nature", "v1_room_id": "R_beach_01", ... }
```
The main room's painted exit (`mapExit`) and Back go to the building's sector map, `#/quartier/<slug>`
(or to `mapExit.href` if given). Label the exit with the sector's name (e.g. "La vallée").

## The per-building rule (for every worker)

A building tarball (`v2-<bld>.tar.gz`) **only adds** these paths:

| path | what |
|---|---|
| `content/v2/<bld>/layout.json` | rooms, painting file names, hotspot boxes (1280×720 px), doors, map exit, zooms, `planned` word lists |
| `content/v2/<bld>/hooks.json` | optional hook overrides `{word_id: {"hook": "...", "why": "..."}}` ; an entry may also (or only) carry `"art"` / `"g"` to fix the article or gender on labels and cards, e.g. `{"fr_hammam_noun": {"art": "le"}}`. `"plaque": true` marks a word shown only as text on a blank museum plaque (nothing depicted, e.g. fr_tuer_verb): check_v2 then skips the content filter on that item's gloss only; hook/scene/note/ex are still checked. `"say"`/`"f_say"`/`"en"`/`"ex"` replace the respelling, gloss or example sentence (e.g. an idiom gloss that trips the content filter), with a `"why"`. |
| `content/v2/vocab_fixes.json` | shared article/gender fixes for known vocab.jsonl errors (le hammam, le hors-d'œuvre, le container), applied to every building; a building's own hooks.json entry wins. A `"g"` change also moves the word's side (f left, m right). |
| `village/v2/<bld>/*.jpg` | one integrated painting per room (1280×720, JPEG q≈86 progressive) |
| `village/v2/<bld>/cards/*.webp` | card crops (generated by the build) |
| `village/v2/data/<bld>.js` | generated payload (`build_v2.py`) |

It **never edits** `village/v2/index.html`, `app.js`, `style.css`, `README.md`, `CHANGES.md`, `data/map.js`,
`map/`, `content/v2/map.json`, `scripts/v2/*`, `scripts/qa/*`, another building's files, or anything outside v2
(v1 data, `data/source/`, `content/rooms/`, …). If you think a shared file must change, stop and report it instead.
Put your change notes in the tarball's top-level `CHANGES.md`, not in the repo.

## Workflow

```
python3 scripts/v2/build_v2.py <bld>                 # writes village/v2/data/<bld>.js + cards
python3 scripts/qa/check_v2.py <bld>                  # static rules
(cd village && python3 -m http.server 8765) &
python3 scripts/qa/check_v2.py <bld> --browser        # rendered overlaps, Back, verb cards, sector map shows <bld> live
python3 scripts/qa/check_v2.py <bld> --browser --strict  # + labels ≥3 px from labels/hotspots/doors/badges, ≥8 px from the scene edge; warnings fail
```
QA must print `PASS`. Then look at every hotspot yourself: the painting must show what the hook says.

## layout.json

```jsonc
{ "building": "boulangerie", "name": "La boulangerie", "main": "boulangerie",
  "roomList": [{"key": "boulangerie", "short": "La boutique"}, ...],     // main room first
  "rooms": { "<key>": {
     "name": "...", "image": "<bld>/<key>.jpg", "alt": "...", "nameplate": [50, 4.5],
     "planned": {"vocabRoom": "R_..."} | {"v1": "<bld>/<room>"} , "only": [ids...] (optional),
     "mapExit": {"box": [x,y,w,h], "label": "La vallée", "href": "#/quartier/nature" (optional)}, // MAIN room only
     "doors": [{"to": "<key>", "label": "...", "hint": "...", "hit": [x,y,w,h]}],  // on a painted door
     "backTo": "<main>",                                                   // sub-rooms
     "zooms": [{"to": "<key>", "label": "...", "at": [x,y], "obj": [x,y,w,h]}], // obj = the object in this painting
     "parent": "<key>" (zoom rooms),
     "items": [{"id": "fr_..._noun", "box": [x,y,w,h], "labelAt": [cx, top] (optional), "text": "vocab" (optional)}]
  } } }
```
* Adjectives (vocab `pos: "adj"`) are allowed: their label has no article, their card shows
  `adjective · côtier/côtière` (or *same for both*) and their box centre must sit in the middle band (30–70 %).
* Adverbs (ids `fr_<key>_adv`) work the same way: no article or gender, card gram line `adverb · invariable`,
  box centre in the middle band (30–70 %).
* Interjections, set phrases and idioms (vocab `pos: "intj"`, `"phrase"`, `"idiom"`) are built like adverbs:
  no article or gender, box centre in the middle band (30–70 %); the card gram line says `interjection · invariable`,
  `phrase · fixed expression` or `idiom · fixed expression`.
* The room list drops below the strip when it does not fit beside the title; the painting is then pushed down
  36 px so the list never covers labels (`--strict` checks this).
* Card text comes from the v1 payload `village/assets/data/<bld>.js` (matched by id), else `data/source/vocab.jsonl`;
  `"text": "vocab"` forces the vocab source. Never copy or edit that text.
* `hooks.json` is only for hooks that break the content rules (crude, scary, drinking/smoking, mature, God the
  Father…) or that cannot be painted; the painting must then show the new hook.

## Rules every painting must satisfy
Ink-outline storybook gouache, whimsical; nothing written in the paintings; each hotspot's object shows its hook;
feminine words in the LEFT half, masculine in the RIGHT (epicene 30–70 %); no overlapping hotspots, labels, doors;
every passage is a painted door with its hit box on it; the main room has a painted exit to the village; zoom
objects are visible in the parent and match it; age-appropriate content; scenes consistent with each other and
with the building on the map painting.
