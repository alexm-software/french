This pass carries out the text-only parts of `docs/PROPOSALS_2026-10-28.md`, `docs/SKILLS_PROPOSALS_2026-10-28.md` and `data/hooks/qa/RECOMMENDED_CHANGES.md`.

## Part A: card text (PR "Text pass")

### Verb cards
- **The note no longer repeats the beret line.** Before, 576 verb cards said "RED beret = regular -er verb." right under the beret line, and 515 now have no note at all. The mirror sentence went too, because the grammar line already shows the mirror.
- **Bare preposition tags removed.** 42 notes had tags like "acheter + à" or "chercher + à", which mislead without an object.
- **New "Patterns" section** between the example and the conjugation tables. It comes from the new hand-written file `data/curated/verb_patterns.json`, which covers 79 verbs; 52 of them are live now. Each pattern gives the construction (*penser à / penser de*), its meaning and an example with audio. There's a "⚠ no preposition" warning on the English-trap verbs (*attendre*, *chercher*, *écouter*, *regarder*, *payer*, *demander*) and a "needs à / dans" warning on the reverse ones (*répondre*, *obéir*, *téléphoner*, *ressembler*, *entrer*). A legend explains *qqn* / *qqch*.
- **Spelling-change badge.** 105 red-beret verbs change their stem spelling (*j'achète / nous achetons*, *commençons*, *je paie*). These now show a "spelling change" badge, and the note gives the actual forms, unless the note already explained them (as on *appeler*).

### Hooks (text only; each painting is unchanged and every hook still describes it)
- **358 hooks: bracketed respelling matched to the card's "say" line.** For example, *actuel* "(ak-TU-el)" → "(ahk-TWEHL)", *immuable* "(ee-mu-ABL)" → "(ee-MWAHBL)", and *repérer* "(ray-pay-RAY)" → "(ruh-pay-RAY)". Only full-word respellings with the same syllable count were changed. Partial chunks such as "(SHWAHR)", and deliberate dropped-schwa forms such as "(ash-TAY)", were left alone so the puns still work.
- **17 hooks reworded without Latin, etymology or the "Linked to …" template, keeping the same painted content:** *aviation*, *pontife*, *crosse*, *nef*, *chaire*, *quête*, *fidèle*, *cortège*, *vitrail*, *chemin de croix*, *prie-dieu*, *clochette*, *clocher*, *bénitier*, *portail*, *enfant de chœur*, *encensoir*. For example, *vitrail* now leads with the painted steam train: "vee-TRAHY ≈ V-TRAIN".
- **8 hooks lost a false "Like English 'X'" opening.** X was the translation, not a look-alike: *parfaitement*, *vivement* (whose "vividly" was also wrong), *fidèlement*, *typiquement*, *prometteur*, *écurie*, *friche*, *sûrement*.

## Part B: site features (PR "Site features")

All in code and generated text data. No painting, card crop or room position changed.

### New: `village/extras.js`
It is loaded after `app.js` and uses only the small `window.Village` API that `app.js` now exposes.

**Header**
- A **Search** button (key `/`) searches all 3,904 placed words in French or English, with accents optional. Choosing a result walks to the room and opens the card (`#/building/room?w=id`).
- A **Menu** button (key `M`) carries a badge with the number of words due.

**Menu**
- **Recall mode** (key `R`). Labels hide. Tap an object, type or say its name, check or show the answer, then grade it: Knew it / Almost / Didn't know.
- **Find it.** A word is called out and spoken; tap the object it belongs to.
- **Review.** Spaced repetition (boxes of 1, 3, 7, 16 and 35 days), kept in this browser. Review walks you back to each due word in its own room and makes it glow, so the place does the reminding.
- **Words in this room.** The list with each word's level and your progress. It exports to Anki (.tsv with headword, English, IPA, say, example and hook) and prints.
- **Conversations.** The 54 dialogues for the 18 rooms that have them. Tap a line for the English; 🔊 reads it aloud.
- **Show what you can click** (same as the ✦ button, which is hidden on phones together with full screen to give the title room).
- **Settings.** Speech speed, a level filter (A1 to C2: words above the level are hidden in every room), and a progress reset.
- **Help** (key `?`, shown on the first visit). Explains the sides, berets, mirrors, spelling-change badge, patterns, false-friend flags and keys.

**Cards**
- A CEFR level badge.
- "Stands on the left/right" on nouns.
- Tap the picture to enlarge it.
- Previous and next word in the room.
- "I know this" and "Practise it".
- "Also in" links when the same word lives in another room.

**Offline and install**
- `sw.js` caches the app shell, and caches each painting and room the first time you open it.
- `manifest.webmanifest`, with a small drawn SVG icon (`icon.svg`, a new file), lets the site be installed to a phone's home screen.

### `village/app.js`
- The `window.Village` API: onCard, onRoom and onView hooks; openCard, closeCard, speak, headword, hasVoice, here, roomHref, stage; and a speech rate.
- Deep links `#/building/room?w=id` open a card.
- The map reads which buildings are live from `data/live.js` instead of requesting a data file for every planned building (about 58 failed requests per map load before).
- Listen buttons only show when the browser has a French voice.
- In conjugation tables, alternative forms (je paye beside je paie) are greyed.
- Building names on sector maps follow the Labels switch.

### Build
- `scripts/v2/build_v2.py` now copies each word's CEFR level into the room data.
- `scripts/v2/build_extras.py` (new) writes `village/data/live.js`, `index.js` (the search index) and `dialogues.js` (only dialogues whose room exists). Run it after `build_map.py`. Both READMEs give the new step.
