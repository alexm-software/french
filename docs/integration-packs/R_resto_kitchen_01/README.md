# Chef’s kitchen — R_resto_kitchen_01

A standalone pack:14 requested words across two separate integrated paintings, matching the previous kitchen’s white tiles, sage cabinetry, copper utensils and chef-hat extractor. No repository, map or navigation changes.

- scene-01.jpg: tasting pass — recette, amertume, soupe, saveur, délicieux, cuisinier, goût.
- scene-02.jpg: preparation bench — menthe, préparation, frite, sauce, grillé, culinaire, haricot.

manifest.json contains authoritative word IDs, meanings, pronunciation, contextual hooks, gender/POS and fitted boxes in1280×720 pixels as[x,y,width,height]. Helpers and their cue props share one box. Ordinary background furniture and produce remain scenery. Feminine nouns sit left, masculine nouns right, adjectives central.

The clean paintings are separate from the numbered placement proofs. cards/ holds word crops. dialogues.json and dialogue.md contain12 natural bilingual turns practising all14 words, with normal plural forms. words.csv offers a flat handoff table. Run python validate.py for the portable geometry/inventory check.

The final paintings were recovered intact from their saved original image outputs after the pause; their placement metadata and dialogue were rebuilt from the retained design. No artwork was regenerated for this kitchen. Meaning notes and image hashes are in manifest.json. The approximate COOL/NEAR cue for culinaire is a memory aid, not a pronunciation guide; the source IPA remains authoritative.
